interviewQA:
  - question: "웹뷰 안에서 로그인 상태는 어떻게 관리했나요?"
    answer: "웹에서 로그인하면 쿠키가 생기기 때문에, 앱에서는 @react-native-cookies/cookies 라이브러리로 쿠키를 읽어서 로그인 상태를 판단했습니다. 쿠키가 없으면 로그인 버튼을 보여주고, 로그인 페이지에서 웹 로그인이 끝나면 웹뷰를 새로고침해 상태를 반영했습니다. 쿠키가 있으면 로그아웃 버튼을 보여주고, 로그아웃할 때는 쿠키를 삭제한 뒤 웹뷰를 새로고침했습니다."
  - question: "웹뷰 앱을 네이티브 앱처럼 자연스럽게 만들기 위해 어떤 처리를 했나요?"
    answer: "웹사이트를 그대로 띄우기만 하면 앱이라기보다 브라우저처럼 느껴져서, 네이티브 동작을 하나씩 연결했습니다. 로딩 중에는 로딩바를 보여주고, 뒤로가기·앞으로가기·새로고침 버튼과 Pull To Refresh, 네이티브 공유 기능을 넣었습니다. 안드로이드 백버튼도 웹뷰의 뒤로가기와 연결했고, 앱에서 어색한 핀치 줌, 텍스트 롱 프레스, 링크 롱 프레스 프리뷰는 비활성화했습니다. 웹사이트의 요청을 가로채서 새로운 스크린으로 이동시키는 처리도 했습니다."
  - question: "웹사이트를 앱으로 감싸면서 웹과 네이티브의 차이를 체감한 점은 무엇인가요?"
    answer: "웹사이트를 웹뷰에 띄우기만 해도 화면은 나오지만, 앱으로 쓰기에는 어색한 부분이 많았습니다. 핀치 줌, 텍스트 롱 프레스, 링크 롱 프레스 프리뷰처럼 브라우저에서는 자연스러운 동작이 앱에서는 오히려 어색해서 비활성화했고, 안드로이드 백버튼도 웹뷰의 뒤로가기와 직접 연결해야 했습니다. 로그인 상태도 브라우저는 쿠키로 알아서 유지하지만, 앱에서는 쿠키를 직접 읽고 지워서 화면에 반영해야 했습니다. 브라우저가 대신 해 주던 일들을 앱에서는 하나씩 직접 정해야 한다는 점을 체감했습니다."
  - question: "이 학습 프로젝트를 시작하게 된 계기는 무엇인가요?"
    answer: "저축하나로에서 Swift와 WKWebView로 하이브리드 앱을 만들어 본 경험이 있어서, 같은 구조를 React Native에서는 어떻게 만드는지 직접 익혀 보고 싶었습니다. 그래서 네이버 웹을 앱에서 쓰는 상황을 가정하고, 웹뷰 로드와 화면 이동, 쿠키 기반 로그인, 공유와 뒤로가기 같은 네이티브 기능 연동을 하나씩 구현해 봤습니다."
  - question: "웹과 앱이 서로 데이터를 주고받아야 할 때는 어떻게 처리했나요?"
    answer: "네이버는 제가 수정할 수 없는 외부 웹사이트라서, 웹에 postMessage 코드를 넣는 브릿지 방식은 쓸 수 없었습니다. 대신 앱 쪽에서 웹의 상태를 읽는 방식으로 처리했습니다. onShouldStartLoadWithRequest로 웹의 페이지 이동 요청을 가로채 URL을 새 스크린에 넘겼고, 로그인 화면에서는 onNavigationStateChange로 로그인 완료 후 이동하는 URL을 감지해 다른 웹뷰들을 새로고침했습니다. 로그인 여부는 쿠키에 세션 값이 있는지로 판단했고, 반대로 앱에서 웹으로는 injectedJavaScript로 스크립트를 주입해 핀치 줌과 텍스트 선택을 막았습니다."

### 📱 하이브리드앱

네이버 웹을 앱에서 사용할 수 있는 어플리케이션

### 🛠️ 사용 기술

- TypeScript
- React-Native
- Context Api

### 👩‍💻 개발 사항

- 웹뷰에 웹사이트 로드 및 웹사이트 리퀘스트를 처리하여 새로운 스크린으로 이동
- 웹사이트 로드 중 로딩바 구현
- 웹사이트 브라우징 시 네이티브 앱에서 뒤로가기, 앞으로가기, 새로고침 기능 구현
- Pull To Refresh 기능 개발
- 네이티브 공유 기능 개발
- 쿠키 동기화하여 로그인 기능 개발
- 핀치 줌/아웃, 텍스트 롱 프레스 액션 비활성화
- 링크 롱 프레스 시 프리뷰 비활성화
- 안드로이드 백버튼과 웹뷰 연결

### 💡 프로젝트 회고

#### 웹뷰에서 로그인 기능 개발하기

```markdown
# 쿠키가 없는 경우 프로세스
read 쿠키 -> N -> show 로그인 버튼 -> 로그인 페이지로 이동 -> 웹에서 로그인 완료 -> 웹뷰 새로고침
```
```markdown
# 쿠키가 있는 경우 프로세스
read 쿠키 -> Y -> show 로그아웃 버튼 -> 쿠키 삭제 -> 웹뷰 새로고침
```
→ 쿠키 관리 라이브러리는 [@react-native-cookies/cookies](https://github.com/react-native-cookies/cookies) 사용.
