### 7. 웹뷰와 네이티브 사이의 JS 브릿지는 어떻게 구현하셨나요?

> 맥락: saving-hanaro
> 첫 글자 6.2초 · 전체 27.4초 · 입력 2226 토큰(6.1초) · 출력 475 토큰 · 22.4 tok/s

웹뷰와 네이티브 사이의 JS 브릿지는 주로 `WKScriptMessageHandler`를 활용하여 구현했습니다. 웹 페이지에서 특정 이벤트가 발생할 때, 예를 들어 애플 로그인 버튼을 누르면 JavaScript를 통해 네이티브 부분으로 메시지를 전송합니다. 구체적으로는 다음과 같은 과정을 거쳤습니다:

1. **WKUserContentController 설정**: 메시지 핸들러를 등록합니다.
    ```swift
    let contentController = WKUserContentController()
    contentController.add(self, name: "appleLoginBtnClick")
    ```

2. **WKWebView 구성**: 웹뷰를 설정하고 사용자 콘텐츠 컨트롤러를 연결합니다.
    ```swift
    let configuration = WKWebViewConfiguration()
    configuration.userContentController = contentController
    defaultWebView = WKWebView(frame: .zero, configuration: configuration)
    ```

3. **네이티브 메시지 핸들러 구현**: Swift에서 메시지를 수신하고 처리하는 핸들러를 정의합니다.
    ```swift
    extension ViewController: WKScriptMessageHandler {
        func userContentController(_ userContentController: WKUserContentController, didReceive message: WKScriptMessage) {
            if message.name == "appleLoginBtnClick" {
                // 애플 로그인 처리 로직
                handleAppleLogin(message: message.body)
            }
        }
        
        private func handleAppleLogin(message: Any) {
            // 애플 로그인 로직 구현
            // 로그인 완료 후 결과를 웹으로 다시 전달
            self.webView.evaluateJavaScript("responseToken(\(JSONSerialization.data(withJSONObject: message).base64EncodedString())") { result, error in
                if error != nil {
                    print("Error evaluating JavaScript: \(error!)")
                }
            }
        }
    }
    ```

이렇게 하면 웹에서 네이티브로 메시지를 보내고, 네이티브 측에서 해당 메시지를 처리하여 필요한 작업을 수행할 수 있습니다. 이 방법을 통해 애플 로그인과 같은 네이티브 기능을 웹 기반 UI에서 원활하게 구현할 수 있었습니다.
